### Install on O2 at Harvard Medical School ###
<h3><img align="center" width="25%" src=../images/cloud_computing_640_3.jpg></h3>

O2 is a high-performance computing platform based on Linux, located at Harvard Medical School. The platform is managed by the Research Computing Group, which is part of HMS IT. You can find documentation on O2 at the [O2 documentation website](https://harvardmed.atlassian.net/wiki/spaces/O2/overview?homepageId=1586790623).

Please note that the cluster does not currently support Docker. To install the necessary packages, including the detectron2 library, follow the [instructions for installation on O2](./docs/O2_install.md).
